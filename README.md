\#\# Key Features

1\. \*\*Strict Identity Isolation:\*\* Enforces zero cross-contamination across three separate professional identities (\*Adnan Obuz\*, \*Edward Obuz\*, and \*Adnan Menderes Obuz\*) and purges legacy terms.  
2\. \*\*Anti-AI Detection Linter:\*\* Removes 20+ telltale AI clichés (\`delve\`, \`tapestry\`, \`nuanced\`, \`landscape\`, \`testament\`, etc.).  
3\. \*\*Punctuation & Cadence Normalizer:\*\* Automatically converts rigid em-dashes (\`—\`) and semicolons (\`;\`) into conversational ellipses (\`...\`) for executive cadence.  
4\. \*\*Rank Math & Technical SEO:\*\* Enforces character boundaries (title ≤ 60 chars, meta description 150-160 chars) and injects target identity focus keywords.  
5\. \*\*Robust WordPress REST API Integration:\*\* Utilizes native UTF-8 JSON serialization to prevent long-text payload corruption (\`rest\_invalid\_json\`) and includes pre-publish duplicate slug detection.  
6\. \*\*Platform Adaptations:\*\* Automatically formats articles for:  
   \- \*\*Authority Core:\*\* WordPress (self-hosted canonical root).  
   \- \*\*Network Multiplier:\*\* LinkedIn (300-500 word mobile hook format).  
   \- \*\*Syndication Ring:\*\* Dev.to, Medium, Substack, and GitHub with canonical backlinks.
